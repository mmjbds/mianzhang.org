Discovery surface

One canonical index.

sitemap.xml lists independently canonical HTML pages. Machine-readable datasets, receipts, manifests, and keys remain public through their parent pages and direct links without being presented as search landing pages.

robots.txt and llms.txt expose crawler and answer-engine entry points. The Hugging Face surface is a technical mirror; duplicated pages consolidate to this domain.

Decision boundary

Acceptance is not outcome.

A successful API response establishes receipt by that endpoint only. Claims about index coverage, search position, referral traffic, backlinks, or model citation require their own dated evidence.
