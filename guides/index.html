Can an answer change the situation it describes?

ReflexBench compares observer-participant reasoning across four observer-depth levels. The public browser contains 20 scenarios; its orientation receipt is not an automated benchmark score.

WisdomBench examines failure and feedback over repeated episodes. Check the released task protocol, scoring and run evidence before interpreting improvement as general learning.

What must be checked before an agent acts?

Proof-Carrying Action separates evidence and permission from fluent answers. The mini gate illustrates ACT, WAIT, QUERY and REFUSE; passing it does not certify a deployed system.
